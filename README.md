# 🧟 Zombie Survivor

**一款手机优先的僵尸生存射击游戏**

## 📱 平台支持
- ✅ Android (720x1280)
- ✅ Windows
- ✅ macOS
- ✅ Linux

## 🎮 游戏特色

### 核心玩法
- **自动射击** - 只需移动，武器自动攻击最近敌人
- **移动控制** - 虚拟摇杆 / WASD / 鼠标拖拽
- **升级系统** - 每10击杀获得强化选择
- **Boss战** - 每5波出现Boss

### 敌人类型
| 类型 | 血量 | 速度 | 特殊 |
|------|------|------|------|
| 普通僵尸 | 10 | 50 | 基础敌人 |
| 快速僵尸 | 8 | 70 | 速度快 |
| 坦克僵尸 | 30 | 30 | 高血量 |
| 爆炸僵尸 | 5 | 60 | 靠近爆炸 |
| Boss | 500 | 30 | 每5波出现 |

### 武器系统
- **手枪** - 平衡型，初始武器
- **霰弹枪** - 近距离高伤害 (50击杀解锁)
- **步枪** - 远程高伤害 (100击杀解锁)

### 强化选项 (每10击杀3选1)
- 伤害提升
- 射速提升
- 移动速度提升
- 子弹数量增加
- 穿透弹
- 暴击率提升
- 生命上限提升

## 🎯 操作方式

### 移动端
- **左侧屏幕** - 虚拟摇杆移动
- **右侧屏幕** - 自动射击
- **手雷按钮** - 范围伤害

### PC端
- **WASD / 方向键** - 移动
- **鼠标左键** - 移动
- **空格键** - 投掷手雷
- **鼠标中键** - 投掷手雷

## 📊 游戏系统
- **成就系统** - 6个可解锁成就
- **统计系统** - 追踪击杀、胜率、时间
- **商店系统** - 解锁新武器
- **设置菜单** - 音量、音效控制

## 🏗️ 技术栈
- **引擎**: Godot 4.7.1
- **语言**: GDScript
- **分辨率**: 720x1280 (移动端优先)
- **渲染**: 2D Canvas
